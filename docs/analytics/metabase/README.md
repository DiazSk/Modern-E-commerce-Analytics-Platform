# Metabase Documentation

This directory contains the operational documentation for the Metabase BI service.

## Primary Reference

**[metabase-operations-runbook.md](./metabase-operations-runbook.md)** — single source of truth for:

- Service bootstrap and connection settings
- PostgreSQL source schema reference
- Initial Metabase configuration
- Dashboard catalogue (Executive, Product Performance, Customer Analytics, Funnel Analysis)
- Complete SQL query reference
- Troubleshooting and performance tuning
- UI reference

## Quick Access

- **Metabase URL:** `http://localhost:3001`
- **Bootstrap:** `docker-compose up -d`
